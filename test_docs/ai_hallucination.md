分类
根据模型输出与输⼊信息源的关系，幻觉可分为[1]：
内在幻觉：输出与输⼊内容相⽭盾，如摘要与原⽂不符；
外在幻觉：输出⽆法从输⼊中验证，既⾮错误，也可能包含真实的外部信息，常⻅于开放式⽣成
任务。
OpenAI团队则按推理范围将幻觉分为[15]：
封闭域幻觉：在给定上下⽂中⽣成超出信息源的虚构内容；
开放域幻觉：模型在⽆特定输⼊背景下⽣成错误信息，例如虚构⽂献、案例或数据。
从⽭盾来源划分，幻觉可分为[16]：
输⼊⽭盾幻觉：模型输出与⽤⼾指令或输⼊信息不⼀致；
上下⽂⽭盾幻觉：⽣成内容内部前后不⼀致；
事实⽭盾幻觉：输出与现实世界知识相冲突。
成因
数据层
⼤模型依赖于规模巨⼤的语料或图像集合进⾏预训练。为提⾼效率与降低成本，数据收集常采⽤启
发式、⾃动化或弱监督⽅法，⽽⾮对所有样本进⾏⼈⼯严格校验。这种做法虽能迅速扩展数据规
模，但易引⼊噪声、误标或来源不明的信息配对，从⽽使训练数据本⾝含有与输⼊不⼀致或不可验
证的⽬标⽂本∕标签。在模型学习阶段，这些不忠实或嘈杂的训练样本会被吸收为“知识”，进⽽在
⽣成时以⾼置信度再现，导致幻觉的发⽣。[17]
训练语料中的重复短语或近似样本会促使模型“记忆化”输出，⽽⾮学到泛化的映射，进⽽在⽆提
⽰或⻓上下⽂情形下直接复制训练中⻅到的⽂本，造成与输⼊不⼀致的输出[18]。相反，某些事实或
语义类型在训练集中分布稀少（缺失），则会使模型在相关场景上出现⾼不确定性和错误补全，从⽽
产⽣幻觉[19]。跨区域、跨⽂化的数据采集与标注差异也可能引⼊系统性偏⻅，影响模型对事实的判
定与表述[20]。
随着指令微调与对⻬过程对标注数据依赖加深，标注⽅式从⼈⼯向机器辅助甚⾄⾃动化转变，这既
提⾼效率也带来⼀致性和质量问题。合成或模型⽣成的数据如果未经严格审核，就可能把“模型的
错误”再循环进训练集中，形成反馈环，进⼀步加剧幻觉倾向。[19]
模型层
⼀些研究与媒体报道（如《连线》）提出，对抗性幻觉可以被视为⾼维统计现象：在⾼维特征空间
中，模型对微⼩、复杂的统计模式⾮常敏感，这些模式可能在⼈类视觉或直觉下不可⻅，但在训练
数据的统计分布中却有显著关联。例如，在图像识别中，⼀幅对⼈类看来是“狗”的图像可能携带
极细微的纹理或噪声模式，这些模式在训练数据中与“猫”⼀类样本具有统计相关性，因⽽被模型
识别为“猫”。从该⻆度看，所谓“幻觉”的判定部分源⾃⼈类对特征空间的感知盲区，以及模型在
⾼维统计上发现的规律与⼈类语义分类间的错配。[21]
与此同时，上述⾼维统计解释并⾮⽆争议。部分研究者质疑模型“发现隐藏正确特征”的说法，指
出模型往往偏向利⽤表⾯统计规律⽽⾮掌握更深层次的语义或因果关系，因此其在对抗训练或实验
室构造样本上取得的“正确性”难以推⼴到⾃然、真实世界的数据分布。换⾔之，即便模型在某些
受控条件下能利⽤微弱纹理做出统计上合理的判断，其鲁棒性在现实场景中仍可能不⾜，从⽽在真
实应⽤中表现出幻觉或错误。[22]
模型的编码器负责将输⼊映射到内部表⽰，解码器根据该表⽰⽣成输出。如果编码阶段未能准确捕
捉输⼊的核⼼事实或建⽴正确的实体关系，解码阶段可能依据错误或不完整的表⽰⽣成与输⼊不⼀
致的⽂本（即内在幻觉）[23][24]。当模型在表征空间中错误地将相似实体或事实关联时，输出会混
淆两个或多个相似概念，导致事实性错误[19]。
预训练阶段将⼤量统计知识固化为模型参数，模型在⽣成时常常“优先使⽤”这些记忆化信息⽽⾮
实时输⼊或外部检索结果。这种先验偏好在输⼊与先验冲突时会导致模型坚持错误事实[25]。⼤模型
难以及时更新（模型知识的时效性问题）与灾难性遗忘现象，使得模型⽆法在保留既有能⼒的同时
快速吸纳新事实，从⽽在⾯对新知识时产⽣事实性幻觉[19]。
应⽤层
为特定任务或领域（如法律、医学、⾦融）进⾏微调时，模型可能变得对该领域内的分布敏感但对
跨域泛化能⼒下降。当实际输⼊偏离微调数据分布时，模型更容易出现幻觉性输出。[26]
主流模型⼤量采⽤相似架构（如Transformer）和类似的数据处理管线，这种“同质化”使得某⼀
类设计缺陷或训练偏差可能被⼴泛复制到多种模型与产品中，从⽽在产业层⾯系统性放⼤幻觉⻛
险[26]。
将⽂本、图像、⾳频等多模态信息融合的模型⾯临不同模态间对⻬问题。若模态间特征抽取或对⻬
策略不当，模型可能在⽣成时误⽤某⼀模态的局部特征作为事实依据，产⽣跨模态的幻觉（如视觉
提⽰产⽣的“物体幻觉”）。[19]
提⽰⼯程（包括指令微调与思维链提⽰）在提升模型可控性与可⽤性⽅⾯成效显著，但若提⽰设计
不充分或含有合成/错误⽰例，模型可能被引导⽣成不忠实或虚构内容[19]。思维链提⽰虽然增强了
模型推理能⼒，但若其内部推理步骤未被有效验证，也可能导致看似合理但事实错误的输出[27]。
伦理与法律⻛险
随着⼤模型在司法、医疗等⾼⻛险领域的应⽤，其幻觉输出可能造成不可逆的损害。在司法领域，
若⽤于⽣成裁判⽂书的模型出现事实错误，可能直接影响司法公正及当事⼈权利；在医疗领域，若
⽣成的诊疗建议或药品说明出现幻觉，将威胁患者⽣命安全；在在药品、法律⽂件等⾼精度翻译任
务中，幻觉可能导致误导性内容传播，引发社会信任危机[19]。
⼤模型的⾼拟⼈化表现易导致⽤⼾产⽣过度依赖与信任，⽽⼈类认知中存在的“摩西幻觉”（Moses
illusion）现象，即对似真错误信息的误判，使得公众更难识别幻觉⻛险[28]。
截⾄2026年6⽉14⽇，加拿⼤各法院及法庭已收到⾄少167份包含⼈⼯智能⽣成之虚构引⽂的诉讼
材料，涉及51个法院及法庭。[29][30]
评估⽅法
传统的度量指标（如BLEU、ROUGE）往往难以有效量化幻觉⽔平，且与⼈⼯评判的相关性较
低[1][31]。针对这⼀问题，依据评估的侧重点与幻觉成因，⽬前⼤模型幻觉的评估⽅法主要分为三
类：基于数据⽂本的评估⽅法、基于模型的评估⽅法和基于多任务应⽤的评估⽅法[19]。
基于数据⽂本的评估⽅法通过统计指标（如精确率、召回率、F-值）衡量⽣成⽂本与参考⽂本之间
的信息⼀致性，以量化幻觉程度。通常做法是利⽤词汇特征进⾏匹配计算[1]。⼀种⽅法是以⽬标⽂
本为参考，将⽬标⽂本作为基准计算统计指标[32][33][34]；另⼀类是以源⽂本为参考，在评估时不依
赖⽬标⽂本，更适⽤于多样化输出场景[35][36]；还可以基于多参考⽂本的扩展⽅法[37][38]。该类⽅
法从数据层⾯评估模型的幻觉程度，常⽤于检测内在幻觉、封闭域幻觉及上下⽂⽭盾幻觉。但其局
限在于难以从语义理解层⾯准确识别幻觉[19]。
基于模型的评估⽅法利⽤额外的模型对⽣成⽂本进⾏语义分析，以更精确地判断幻觉。这类⽅法⼤
致分为两步: 先利⽤模型对⽂本进⾏学习; 再根据学习结果判断⽣成⽂本中的幻觉。[19] 信息提取⽅
法通过抽取⽣成⽂本与参考⽂本中的事实元组进⾏对⽐评估幻觉[39][40][41]，适⽤于事实⽭盾幻觉与
开放域幻觉，但其准确性依赖于信息提取模型的性能，可能因提取误差导致评估偏差[19]。基于模型
推理的评估⽅法以⾃然语⾔推理为基础，通过判断⽣成⽂本（假设）与参考⽂本（前提）之间的蕴
含、⽭盾或中⽴关系来检测幻觉，并⽤蕴含概率量化幻觉程度[1][42][43](常⽤的模型有BERT[44], 以
及在此基础上发展出的RoBERTa[45]、DeBERTa[46]等），适⽤于输⼊⽭盾幻觉、上下⽂⽭盾幻觉及
事实⽭盾幻觉等场景，但仍⾯临泛化能⼒与指标扩展性不⾜的问题[19]。基于特定模型的评估⽅法利
⽤特定语⾔模型结构直接量化幻觉；该类⽅法普适性强，可应⽤于多种场景，但依赖模型性能与数
据完备性[19]。
基于问答的评估⽅法通过⽣成问题与答案隐式评估模型幻觉⽔平[31]，该类⽅法主要⽤于检测摘要任
务中的外在幻觉及事实⽭盾幻觉，但仍受限于所⽤QA模型的精度[47][48][49][19]。基于分类的评估⽅
法通过构建带标签数据集对幻觉进⾏分类检测，该类⽅法需明确幻觉类别，强调建⽴细粒度幻觉分
类体系[19]。
基于特定任务指令的评估⽅法利⽤特定指令任务构建评估基准。该类⽅法具有较强的任务适配性，
可⼴泛应⽤于法律、⾦融、健康等专业领域的幻觉检测[19]。
缓解⽅法
幻觉现象仍未完全被了解[1]。 因此，从业者仍在进⾏研究以试图减轻/减缓其出现[50]。特别是，研
究表明，语⾔模型不仅会产⽣幻觉，还会放⼤幻觉，即使是那些旨在缓解这⼀问题的模型也遇到了
同样的问题。 [51]
根据幻觉的主要来源，常⻅的缓解⽅法可分为数据层⽅法、模型层⽅法和应⽤层⽅法三⼤类[19]。
数据层
数据层⽅法通过改进训练数据的收集与处理⽅式，提升模型输⼊与输出之间的事实⼀致性和语义对
⻬性，常⽤于缓解内在幻觉、封闭域幻觉、输⼊⽭盾幻觉及上下⽂⽭盾幻觉[19]。
由于不忠实或不准确的数据会导致模型幻觉，研究者提出了多种构建⾼保真数据集的⽅法，以取代
传统启发式数据收集⽅式。例如利⽤知识库半⾃动⽣成“数据到⽂本”语料库的⽅法，包含内容选
择与众包标注两个步骤，以确保数据与⽂本语义的⼀致性[52]。通过删除不被数据⽀持的短语、去语
境化处理以及语法修正等⼿段，⽣成忠实于源数据的⽂本样本，从⽽提升训练数据的准确性与流畅
度[23]。部分研究利⽤模型⽣成样本，并标记输出中是否包含幻觉，从⽽建⽴事实⼀致性评估数据
集[53][54]，这类⽅法可低成本构建评测与训练语料，但仍需较⾼的⼈⼯标注投⼊[19]。
数据预处理包括数据清洗与数据增强两类⽅法，⽤以减少噪声、强化语义⼀致性，并提升模型在不
同输⼊条件下的鲁棒性。数据清洗通过剔除或修正存在噪声、⽭盾或错误标注的数据样本，降低幻
觉⻛险。数据增强通过⽣成更多样化、信息更充分的训练样本来提升模型泛化能⼒。[19]
模型层
模型层⽅法通过优化模型结构、训练过程及解码策略，改善语⾔模型的⽣成机制，以减少幻觉的产
⽣[19]。
模型结构的优化主要集中于编码器与解码器两部分。编码器负责将输⼊⽂本转化为语义向量表⽰。
若编码阶段理解不充分，模型可能错误地关联或解释输⼊信息。改进编码器结构有助于提升模型对
输⼊的语义理解，降低内在与上下⽂幻觉。[19]
解码器负责将语义向量还原为⽂本输出，错误的解码过程易导致输出虚构[19]。研究者提出多种结构
优化⽅案，如多分⽀解码器，可针对内容、流畅性等维度分别建模[55]；不确定性感知解码器，⽤于
惩罚⾼不确定性预测[56]；双解码器结构结合序列与树状结构解码以平衡语法与忠实性[57]；约束解
码⽅法通过词汇或结构约束提升语义正确性[58]。
在模型训练或微调阶段引⼊幻觉抑制策略，是缓解幻觉的重要⽅向。通过修改或扩展损失函数，可
以惩罚幻觉输出、⿎励事实⼀致⽣成。[19]
为提升模型对事实的敏感度，可在训练中加⼊辅助学习任务[19]。如强化学习⽅法，通过设计奖励函
数⿎励模型⽣成忠实⽂本[59]；多任务学习⽅法，共享编码器权重，在翻译、问答等多任务中联合训
练，增强模型的对⻬能⼒和通⽤性[19]。
后处理⽅法是⼀类通⽤且灵活的幻觉缓解技术[19]。该⽅法直接作⽤于模型⽣成的输出内容，不依赖
于修改模型结构或再训练，因此具有⼴泛的适⽤性[19]。其核⼼思想是将⽣成⽂本视为“草稿”，通
过⾃动化的编辑、删除与重写步骤，对事实错误进⾏纠正，从⽽得到最终的⾼质量输出[19]。此类⽅
法通常借助“校正器”模型识别并修正幻觉[60]。例如：
专家模型与反专家模型是通过模型微调实现幻觉控制的另⼀类有效⼿段。其基本原理是利⽤不同性
质的数据集引导模型⾏为：专家模型基于忠实（真实⼀致）的样本训练；反专家模型基于幻觉性样
本训练。两者通过融合或权重控制实现幻觉的动态调节。[19]
应⽤层
提⽰⼯程是⼀种⽆需更新模型参数即可引导⽣成⾏为的策略，通过设计输⼊指令、上下⽂或思维链
提⽰，减少模型幻觉并提升推理质量[61]。合理的提⽰设计可显著改善模型的忠实性。提⽰⼯程⽅法
具有⼴泛的可扩展性，但其关键挑战在于如何设计合理的提⽰结构以确保输⼊有效引导模型⽣成忠
实内容。[19]
事实指导通过在输⼊中注⼊额外的知识、关键词或结构化信息，直接提升模型输出的真实性。其形
式包括关键词指导与外部知识指导两类：关键词指导利⽤关键词或显著性标记引导⽣成过程；外部
知识指导通过检索知识库或专家系统信息补充输⼊。[19]
在多模态智能体（整合语⾔、视觉、语⾳等模态）研究中，幻觉同样⼴泛存在[19]。多模态幻觉通常
表现为模型误识图像对象或错误描述视频内容[19]。研究者通过多模态⼀致性建模与不确定性感知解
码等⽅法加以缓解[19]。对象掩码语⾔模型通过遮蔽图像对象增强⽂本与视觉特征对⻬，从⽽减少幻
觉产⽣[62]。

该名律师曾多次向ChatGPT确认案例的真伪，惟ChatGPT每次均回答案例真实，结果被对家律师
揭发，⾄少6宗案例并不存在，似是伪造。该名律师其后表⽰，后悔依赖产⽣式⼈⼯智能，此前从
